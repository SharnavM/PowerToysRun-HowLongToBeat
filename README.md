# PowerToys Run - HowLongToBeat

An unofficial PowerToys Run plugin for searching game completion times from HowLongToBeat.

## Architecture

- C# PowerToys Run plugin
- Python HowLongToBeat bridge
- howlongtobeatpy integration
- JSON Lines communication over stdin/stdout
- PyInstaller packaged bridge

## Requirements for development

- PowerToys 0.100.0
- .NET 10 SDK
- Python 3.11+
- Git
